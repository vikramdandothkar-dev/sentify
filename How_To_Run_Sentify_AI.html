🚀 Step-by-Step Installation

1 Extract the Project

If you received a zip file, extract it first:

# Windows (PowerShell)
Expand-Archive sentify_ai_project.zip -DestinationPath sentify_ai_project

# macOS / Linux
unzip sentify_ai_project.zip -d sentify_ai_project

2 Navigate to the Project Folder

cd sentify_ai_project

3 Create a Python Virtual Environment

# Windows
python -m venv venv

# macOS / Linux
python3 -m venv venv

4 Activate the Virtual Environment

# Windows (PowerShell)
venv\Scripts\activate

# Windows (Command Prompt)
venv\Scripts\activate.bat

# macOS / Linux
source venv/bin/activate
✅ You should see (venv) appear at the beginning of your terminal prompt.

5 Install Dependencies

pip install -r requirements.txt

This installs all required packages:

PackagePurpose
streamlitWeb application framework
scikit-learnMachine learning (Logistic Regression)
pandasData processing
numpyNumerical computing
plotlyInteractive charts & visualizations
nltkNatural Language Processing
joblibModel serialization

6 Download NLTK Data (One-Time Only)

python -c "import nltk; nltk.download('stopwords'); nltk.download('punkt'); nltk.download('punkt_tab'); nltk.download('wordnet')"
⚠️ This step requires an internet connection. It only needs to be done once.

7 Run the Application

streamlit run app.py

The app will automatically open in your default browser at:

🌐 Local URL: http://localhost:8501
🌐 Network URL: http://<your-ip>:8501 (accessible from other devices on the same network)

🔧 Troubleshooting

ProblemSolution
python not foundTry python3 instead, or add Python to your system PATH
pip install failsUpgrade pip: python -m pip install --upgrade pip
Port 8501 in useRun with: streamlit run app.py --server.port 8502
NLTK data errorRe-run Step 6 with an active internet connection
Module not foundEnsure your virtual environment is activated (Step 4)

⏹️ Stopping the Application

Press Ctrl + C in the terminal where Streamlit is running.

🔄 Running Again Later

After the initial setup, you only need two commands to run the app again:

# 1. Activate the virtual environment
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 2. Run the app
streamlit run app.py
